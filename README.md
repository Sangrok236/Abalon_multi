# 🗡️ 원탁 (온라인)

각자 **자기 폰으로 접속**해서 하는 정체 숨기기 게임.
오프라인(폰 1대 돌려쓰기) 버전: [Sangrok236/Abalon](https://github.com/Sangrok236/Abalon)

## 어떻게 노나요
1. 한 명이 **방 만들기** → 4자리 방 코드 + QR/링크가 나옴
2. 나머지는 QR을 찍거나 링크로 들어와서 이름 입력 → **입장하기**
3. 방장이 앉은 순서(▲▼)와 역할 조합(인원별 추천), 찬반 투표 방식(공개/비밀)을 정하고 **게임 시작**
4. 각자 폰에서 자기 역할을 확인 → 모두 확인하면 게임 진행
   - 대표가 자기 폰에서 원정대를 고르면 모두의 화면에 실시간으로 보임
   - 찬반 투표, 원정 카드도 각자 폰에서 냄
   - 결과 화면에서는 대표(또는 방장)가 "계속"을 눌러 다음으로 넘김
5. 끝나면 정체 공개 → 방장이 "같은 멤버로 다시"
   - 게임 중 화면 위 **☰ 메뉴**: 방장은 언제든 "역할 다시 뽑기"(같은 멤버) / "게임 종료 · 로비로"를 할 수 있어요.

폰이 잠기거나 새로고침해도 **자동으로 자기 자리로 돌아옵니다.**
폰을 바꿨거나 브라우저 기록이 날아갔으면, 같은 방 코드에 **원래 이름**으로 들어오면 자리를 이어받습니다.

## 실행하기

### 노트북 하나로 (같은 와이파이)
```bash
npm install
npm start          # http://localhost:3000
```
다른 폰들은 같은 와이파이에서 `http://<노트북 IP>:3000` 으로 접속하세요.
(노트북 IP 확인: macOS `ipconfig getifaddr en0`, Windows `ipconfig`)

### 인터넷에 올리기 (Render 무료)
[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Sangrok236/Abalon_multi)

위 버튼을 누르면 설정(무료 플랜, 싱가포르 리전)이 자동으로 채워집니다. 직접 하려면:
1. [render.com](https://render.com) 가입 → **New → Blueprint** → 이 저장소 선택 (`render.yaml`이 설정을 다 해줌)
2. 배포가 끝나면 나오는 `https://...onrender.com` 주소로 접속
- 무료 플랜은 15분간 아무도 안 쓰면 잠들어요. 첫 접속에 30초~1분 걸릴 수 있으니 **게임 전에 한 번 미리 열어두세요.**
- 게임 상태는 서버 메모리에만 있어서, 서버가 재시작되면 진행 중인 방은 사라집니다.

WebSocket을 지원하는 Node 호스팅(Fly.io, Railway 등)이면 어디든 `npm start`로 돌아갑니다. 포트는 `PORT` 환경변수를 따릅니다.

## 개발
```bash
npm test   # 규칙 단위 테스트 + 실제 서버를 띄워 5명이 한 판 하는 E2E 테스트
```

| 파일 | 역할 |
|---|---|
| `game.js` | 규칙, 역할 배정, 플레이어별 시야, 방 상태와 모든 액션 검증 (네트워크 무관) |
| `server.js` | 정적 파일 + WebSocket + QR 이미지(`/qr.svg`), 재접속/방 정리 |
| `public/index.html`, `public/client.js` | 모바일 UI (바닐라 JS, 빌드 없음) |

**보안 원칙:** 서버가 각 플레이어에게 **본인 역할과 본인 시야 정보만** 보냅니다. 다른 사람의 역할, 투표 중인 표, 누가 어떤 원정 카드를 냈는지는 클라이언트로 내려가지 않습니다 (개발자도구로 봐도 안 보임). 게임이 끝나야 전체 역할이 공개됩니다.
